# Mine Explorer

SPA-приложение для загрузки XML-схем шахт в формате MIM и просмотра их в 3D.
Позволяет выбирать горизонты и выработки, управлять их видимостью и перемещаться
по схеме. Реализовано в рамках тестового задания на модуль 3D-визуализации
шахты.

---

Ссылка:
[ivanmonichev.github.io/mine-explorer](https://ivanmonichev.github.io/mine-explorer/)

## Запуск

Потребуются Node.js 24.x, npm и браузер с поддержкой WebGL 2. Для полноэкранного
режима нужна поддержка Fullscreen API.

В корне проекта выполните:

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале; по умолчанию это
`http://localhost:5173`.

Сборка и локальный просмотр результата:

```bash
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Бэкенд, ключи API и переменные окружения для запуска
не требуются. Выбранный локальный XML обрабатывается в браузере и не
отправляется на сервер.

Автоматические тесты пока не добавлены. Для ручной проверки основных сценариев:
загрузите корректный и ошибочный XML, проверьте выбор из дерева и сцены, скрытие
объектов, фокусировку камеры, полноэкранный режим и узкий экран.

## Управление камерой

Кликните по 3D-сцене или перейдите к ней клавишей Tab, чтобы включить управление
клавиатурой. Удерживайте клавиши для непрерывного движения:

| Клавиши | Действие                              |
| ------- | ------------------------------------- |
| W / S   | Вперёд / назад по направлению взгляда |
| A / D   | Влево / вправо относительно камеры    |
| Q / E   | Вниз / вверх по вертикали сцены       |
| Shift   | Ускорение в четыре раза               |

Управление работает и в русской раскладке. Поворот камеры — перетаскиванием мыши
с зажатой левой кнопкой; колесо меняет приближение. Клавиши движения прерывают
автоматический перелёт к объекту. При уходе фокуса со сцены или переключении
вкладки движение останавливается. Подсказка доступна в панели инструментов
сцены.

## Технологии и архитектура

React 19, TypeScript 6, Vite 8, Three.js, React Three Fiber, Drei, MobX,
`mobx-react-lite`, Ant Design и CSS Modules. Версии зависимостей зафиксированы в
`package-lock.json`.

| Слой                                          | Ответственность                                                 |
| --------------------------------------------- | --------------------------------------------------------------- |
| [app](src/app/)                               | Точка сборки приложения, тема и локализация Ant Design          |
| [pages/mine-viewer](src/pages/mine-viewer/)   | Композиция страницы, загрузка данных и Fullscreen API           |
| [widgets](src/widgets/)                       | Дерево, панели инструментов, таблица свойств, статус-бар и окна |
| [scene/mine](src/scene/mine/)                 | Геометрия, отрисовка, выбор в 3D и управление камерой           |
| [store](src/store/)                           | Изменяемое состояние загрузки и просмотра                       |
| [infrastructure/mim](src/infrastructure/mim/) | Чтение файла, декодирование, DTO, парсинг и проверка связей     |
| [domain](src/domain/)                         | Независимые типы сущностей и чистые функции работы с топологией |
| [shared](src/shared/)                         | Общие компоненты, типы, функции и константы                     |
